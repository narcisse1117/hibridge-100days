# 신입 100일 생존기

AI가 알려 주지 않는 '우리 회사'의 암묵지를 전수하는 신입사원 온보딩 웹 플랫폼 (프로토타입)

교육공학 프로젝트 · 에듀링크 (김용은 · 오승현 · 육예원)

👉 **바로 보기: https://yongeunkim.github.io/hibridge-100days/**

## 소개
- 가상 기업 ㈜하이브릿지 인사팀 신입이 되어 100일을 보내는 상황 선택형 시뮬레이션
- 이론적 근거: Nonaka & Takeuchi(1995) SECI 모델
  - 공동화(S): 소통 공간 · 표출화(E): 시니어 경험 등록 · 연결화(C): 시나리오 DB · 내면화(I): 게임 플레이와 퇴근 회고

## 화면 구성
| 메뉴 | 사용자 | 기능 |
|---|---|---|
| 100일 게임 | 신입사원 | 상황 카드 선택, 4대 게이지, 다중 시니어 피드백, 퇴근 회고, 100일 엔딩 |
| 소통 공간 | 모두 | 동기방 · 선배에게 물어보기 · 익명 질문방 |
| 경험 등록 | 시니어 | 4문항 5분 템플릿, 상황 카드 미리보기 |
| 운영 대시보드 | HRD 담당자 | 상황별 선택 분포, 자주 막히는 상황, 시나리오 DB 검토 |

## 참고
- 상황 카드와 선배 피드백, 대시보드 수치는 예시이며 시니어·주니어 인터뷰 결과로 교체할 예정입니다.
- 입력한 내용은 각자의 브라우저(localStorage)에만 저장됩니다.
- 별도 설치 없이 `hibridge-100days/index.html`을 브라우저로 열면 실행됩니다.

## 폴더 구조
```
index.html            대표 주소 → hibridge-100days/ 로 이동
hibridge-100days/
  index.html          사이트 (홈 · 소통 공간 · 경험 등록 · 운영 대시보드)
  assets/             로고 · 선배 사진
  game/               3D 100일 게임 (사이트 안에 iframe으로 들어감)
```
